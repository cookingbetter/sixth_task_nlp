# sixth_task_nlp

Учебный mini-product: пайплайн принимает текст, разбирает смысл, классифицирует запрос и возвращает короткий ответ в JSON.

На каждый текст пять шагов. `extract_meaning` читает только сырой текст. `classify` по этому смыслу выбирает категорию, тональность и intent. `structured_fields` собирает из них один объект без нового вызова модели. `final_answer` отвечает по маршруту категории: поддержка даёт шаги проверки, жалоба — спокойное признание проблемы, продажа — короткую выгоду, отзыв — благодарность, общий вопрос — прямой ответ. `self_check` сверяет ответ с исходным текстом и отмечает противоречие или потерянную деталь.

## Структура

- `main.py` — команда запуска и порядок шагов
- `llm_client.py` — вызов API и повтор при временном сбое
- `prompts.py` — формулировки, маршруты и лимиты длины
- `schemas.py` — схема JSON на pydantic
- `examples/demo_inputs.json` — пять демонстрационных текстов, по одному на категорию
- `examples/sample_inputs.json` — десять текстов для проверки категорий
- `check_failures.py` — негативные сценарии без сети и без ключа
- `compare_prompts.py` — сравнение трёх формулировок классификации
- `output/` — JSON-результаты прогона

## Установка

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## API-ключ

В `.env` укажите ключ:

```bash
OPENAI_API_KEY=sk-...
```

Пустые `OPENAI_BASE_URL` и `OPENAI_MODEL` оставляют официальный API и модель `gpt-4o-mini`. Для совместимого API эти две строки можно заполнить.

## Запуск

Пять демонстрационных сценариев:

```bash
python main.py --input examples/demo_inputs.json --output output/demo_results.json
```

Десять примеров с ожидаемой категорией:

```bash
python main.py
```

Результат по умолчанию пишется в `output/results.json`.

Один произвольный текст:

```bash
python main.py --text "Как подготовиться к собеседованию на junior Python?"
```

По умолчанию классификация идёт промптом `plain`. Другой вариант: `python main.py --prompt checklist`. Сравнение трёх формулировок: `python compare_prompts.py`.

Негативные сценарии без ключа и без сети:

```bash
python check_failures.py
```

Временная ошибка API и пустой ответ повторяются до трёх раз. Ответ 400 или 401 не повторяется. Невалидный JSON и пропущенное поле один раз уходят в запасной промпт. Слишком длинная строка после этого обрезается до уже заданного лимита. Если смысл или категория так и не собрались, у этого текста появляется поле `error`, остальные примеры идут дальше. Если сломался только ответ или проверка, результат всё равно сохраняется.

На полном наборе из десяти текстов программа завершается с кодом 1, если категория совпала меньше чем в восьми случаях. На пяти демо печатается тот же счёт, и этот порог прогон не останавливает.
